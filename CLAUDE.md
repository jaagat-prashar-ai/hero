# Working principles

- **Think before coding**: State assumptions explicitly, ask rather than guess when things are unclear, push back on overly complex approaches, and stop if confused.
- **Simplicity first**: Write the minimum code needed to solve the issue, avoid speculation, and never add single-use abstractions.
- **Surgical changes**: Touch only the code required for the task, match the existing style, and do not refactor adjacent broken or working logic.
- **Goal-driven execution**: Establish clear, verifiable success criteria so Claude can execute and loop independently until verified.
